# Captured model and scenery credits

These prototype images are captures of the existing STARFALL renderer. No new third-party asset downloads were made for this review.

- Vanguard: [Nitro Blade by VertaScan](https://sketchfab.com/3d-models/nitro-blade-6c34eb48b0c44667864a2af3fed92d6c), [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Existing optimized geometry and reconstructed materials, rendered to a review image.
- Phantom: [Quaternius Ultimate Spaceships](https://quaternius.com/packs/ultimatespaceships.html), CC0. Existing game geometry, captured for this review.
- Scout drone components: Quaternius [Cyberpunk Game Kit](https://quaternius.com/packs/cyberpunkgamekit.html), [Ultimate Space Kit](https://quaternius.com/packs/ultimatespacekit.html), and [Sci-Fi Modular Guns](https://quaternius.com/packs/scifimodularguns.html), CC0. Existing composite game model, captured for review.
- Blaster components: Quaternius Sci-Fi Modular Guns and [Kenney Blaster Kit](https://kenney.nl/assets/blaster-kit), CC0. Existing game model, captured for review.
- Rift enemies and Mothership: original custom Blender geometry authored for STARFALL in the preceding graphics pass.
- Orbital scenery: existing original generated STARFALL orbital environment plate.
- Music: three original procedural synthesis studies composed for this review; source included. They do not contain sampled commercial recordings.

Full original licenses, source links and the live game's About credits remain unchanged in the repository and game.
